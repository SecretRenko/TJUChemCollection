# TJUChemCollection

天津大学化学课程的非官方学习资料合集，用于课程复习、交流与查漏补缺。

## 资料索引

| 课程 | 学期 | 内容 | 在线查看 |
| --- | --- | --- | --- |
| 高等有机化学 | 2025–2026 学年第一学期 | 期末试题（回忆版） | [PDF](courses/advanced-organic-chemistry/2025-2026-sem1/25-26第一学期高等有机化学期末.pdf) |

每份资料按“课程 → 学期”组织，源文件、插图与可直接阅读的 PDF 放在同一资料目录中。

```text
courses/
└── advanced-organic-chemistry/
    └── 2025-2026-sem1/
        ├── README.md
        ├── exam.tex
        ├── 25-26第一学期高等有机化学期末.pdf
        ├── figures/
        └── sources/
```

## 使用方式

- 只需阅读资料：直接打开索引中的 PDF。
- 修改或重新编译：进入对应学期目录，使用 XeLaTeX 编译 `exam.tex`。当前文档依赖 ElegantBook 文档类、方正字体及若干 LaTeX 宏包。
- 反馈错误或补充资料：欢迎提交 Issue 或 Pull Request。
